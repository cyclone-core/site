# 官网改版设计：工程图纸风 × 规格书叙事

> **日期**：2026-09-11
> **状态**：设计定稿，待用户审阅
> **范围**：风格 + 板块叙事重组（内容素材不重写、卖点不重新提炼）

---

## 1. 背景与目标

现官网（index.html 单页双语 + Jekyll 博客 7 篇）功能完整但视觉朴素。目标：让目标客户（检测机构测试主管、OEM/Tier1 测试团队、机器人公司、架构师）眼前一亮——**极客、先锋、酷炫、优雅**。

已定方向：

- **风格**：B · 工程图纸。浅色"技术规格书"质感——发丝线、条款编号、等宽数字、红绿批注。与产品灵魂（诚实的尺子 / 机器证明 / 可复算）同频；别家 dev tool 都做深色，无人做"计量院风格"，差异化最强。
- **叙事**：整站 = 一份《Cyclone 规格书》。Hero 是封面，板块是 §01–§10 条款，诚实标签是批注章，博客是技术笔记 TN-01…07，页脚是文档控制块。

## 3. 封面（Hero）设计

- **眉线**：左 `CYCLONE SPECIFICATION`，右 `DOC NO. CY-SPEC-001 · REV 2026-09-11`（等宽、小字号、字距拉开），下方 1px 墨线。
- **标题**：保留现主标"同一个 case hash，永远同一个测试结果。"，800 字重、紧字距。
- **摘要框**：`摘要 / ABSTRACT` 标签 + 现 hero sub 文案，左侧 3px 墨线。
- **FIG. 0-1 运行实录**：深色终端块保留（浅色文档中的"实物打印件"），带图号与图注"同一用例两次运行，SHA-256 逐字节一致"。
- **验证条**：状态点一行——绿● 261 tests / 绿● bitwise reproducible / 绿● Wilson·SPRT / 琥珀● rules_cyclone 原型 / 灰○ single binary 规划中。
- **按钮**：方形、1px 墨框、等宽小字；主按钮墨底反白。`预约 POC 演示 →`、`§A · 获取场景包`。
- **底纹**：封面区淡淡方格纸纹理（repeating-linear-gradient，透明度 ~4.5%），正文区不用。

## 4. 视觉系统

- **色彩**：纸 `#fdfdfa` / 墨 `#16181a` / 发丝线 `#d9d9d2` / 灰注 `#6b6f6b` / 绿 `#0a7a2f` / 红 `#c01818` / 琥珀 `#a06a00` / 终端块 `#10141a`。
- **字体**：中文/正文沿用系统栈；所有编号、数据、标签、图注用 `ui-monospace` 栈。**不引入外部 webfont**（性能 + 国内访问稳定）。
- **组件**：
  - 条款头：等宽小号 `§01 · PROBLEM STATEMENT` + 中文条款名（19px/700）。
  - 条款行：编号列（等宽灰）+ 内容列，行顶虚线发丝线。
  - 状态点：●绿 已支持 / ●琥珀 原型验证中 / ○灰 规划中——取代现有 pill 形 `.tier` 徽章（表格与卡片内联处可保留小字文字标注）。
  - 图件：所有终端块/图片统一 `FIG. x-y` 图号 + 图注。
  - 按钮：方形墨框（见 §3）。
  - 表格：保留现有 hairline 风格，表头改等宽小号大写。
- **动效**：克制——仅条款区块滚动淡入（IntersectionObserver，`prefers-reduced-motion` 时关闭）；无其他动画。
- **双语**：沿用现有 `span.zh/span.en` + `data-lang` 切换机制；条款编号双语共用，英文标签小号大写。
- **移动端**：条款行折列、封面标题降号、方格纹保留。

- post.html 同套视觉：眉线 `CYCLONE TECHNICAL NOTE · TN-0x`，标题、日期、系列保留。
- 正文排版规格书化：表格 hairline、代码块深色保留、名词解释表不动。
- 首页博客列表（附录 C）每项加 TN 编号。
- 文末 CTA、系列导航保留，按钮换方形样式。

## 6. 技术约束与验收

- 纯静态 Jekyll，无构建工具、无 JS 框架；`jekyll build` 必须通过。
- 单文件 index.html 继续自包含（CSS 内联 `<style>`），文章用 `_layouts/post.html`。
- 验收：
  1. `jekyll build` 零 error；
  2. 中英切换全站无残留串扰；
  3. 所有既有诚实标签状态点化后语义不变（已支持/原型/规划中数量不变）；
  4. 所有既有链接锚点可用（含博客 CTA 指向 #scenariopack 等）——锚点 id 重命名时同步更新导航与博客 front matter；
  5. 移动端 640px 断点正常折行；
  6. 演示数据声明、版本日期页脚保留，版本日期更新为上线日。

## 7. 非目标

- 不重写卖点文案、不新增内容素材；
- 不动两份 PDF 与 roadmap 图；
- 不加分析统计脚本、不加评论系统；
- 不改发布主体相关表述（待用户另行决策）。
