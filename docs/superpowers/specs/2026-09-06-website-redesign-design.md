# Cyclone 官网改版设计（结合 Applied Intuition 对标）

- 日期：2026-09-06
- 项目：https://www.cyclone-xil.com/ （仓库 `cyclone-core/site`，GitHub Pages 静态托管）
- 现状：单文件 `index.html`（约 320 行，中英双语切换）+ 2 个 PDF + 2 张 webp

## 1. 业务目标与定位决策

| 决策项 | 结论 |
|---|---|
| 首要业务任务 | **获取 POC 线索（约 30 分钟演示）** |
| 可用证据素材 | 只有技术资产（测试数据、case hash 证据、演示流水线），无客户 Logo / 案例 / 第三方背书 |
| 首选受众 | 三类都承接：主机厂智驾测试团队 / Tier1 / 机器人公司（首页受众分流） |
| 站点结构 | **增强版单页**（不扩多页，不建文档子站） |
| 视觉方向 | **C：白底 + 深色证据带**（混合风） |
| CTA 承接 | **邮箱 + 微信双通道**（不引入表单后端） |
| 语言 | **双语并重**，沿用现有切换机制 |
| 叙事结构 | **A：证据先行**（Hero → 证据带 → 其余段落） |

### 对标结论（Applied Intuition）

可借鉴：导航分栏、**证据前置**、分层 CTA、资源做线索捕获。
学不来：宏大愿景口号与多行业铺开——无客户证据支撑时显空。
Cyclone 的差异化打法：没有客户 Logo 墙，就把"机器可验证的证据"本身前置为第一屏主角——"不信？你自己验"，这是 Applied 也没有的资产。

## 2. 页面结构（自上而下 11 段）

1. **导航**：品牌 + 锚点（证据 / 方案 / 路线 / 资料）+ 语言切换；锚点平滑滚动
2. **Hero（白底，延续）**：主标语「同一个 case hash，永远同一个测试结果。」+ 副标 + 压缩为两句话的 sub + 现有终端演示
3. **深色证据带（新增核心段）**：白底 Hero 之后紧跟全宽深色带
   - 左栏：标题「不信？你自己验。」+ 三步验证（跑两次 → 比 hash → 看 manifest 报告）
   - 右栏数据点 pill：261 项自动化测试全绿 / 逐字节可复现 / JUnit · Bazel 原生 / M0→M3 十二周
4. **受众分流三卡**：主机厂（可审计证据，锚到边界段）/ Tier1（接入现有工具链，锚到接入段）/ 机器人（5 分钟跑通，锚到接入段）；每卡一句话价值 + 一条支撑
5. **四支柱**：保留，文案压缩到两行以内
6. **一条流水线**：保留现状（含 facts 行）
7. **痛点→答案对照**：原痛点×3 段改造成「老问题 → Cyclone 答案」对照格式，位置后移做强化
8. **划清边界**：保留现状
9. **演进路线**：保留现状（图片 + PDF 链接）
10. **资料下载**：保留两张下载卡 + POC 不公开说明
11. **CTA + 页脚**：标题「拿你自己的场景跑一次」；主按钮「约 30 分钟演示」→ mailto:caojian258@icloud.com；次按钮「加微信 jiancao258」→ 点开微信二维码浮层（二维码图片需用户提供，路径 `assets/wechat-qr.png`；未提供或加载失败时回退为文字显示微信号）；GitHub 仓库降级为文字链接；页脚补邮箱 + 微信号

## 3. 视觉系统

- 色板：白底体系不变（ink `#1a1a1a` / 主绿 `#0a7a2f`）；新增深色带（底 `#0c1014` / 带上强调绿 `#3fd08c` / 辅助灰蓝 `#9fb3c8`）
- 字体：系统字体栈，无外部字体请求；终端/hash/数据一律等宽
- 组件：深色证据带、数据点 pill、受众卡、双层 CTA 按钮（主按钮黑底，hover 变绿）
- 响应式：窄屏受众卡竖排、证据带左右堆叠为上下、终端框横向滚动

## 4. 技术实现

- 单文件 `index.html` 内联 CSS/JS，无构建步骤，GitHub Pages 直接服务，不引入框架
- 双语机制沿用 `body[data-lang]` + `localStorage` + `navigator.language` 探测（不动）
- 新增：og/seo meta 补全；锚点 `scroll-behavior: smooth`；微信二维码资源
- 无任何外部 CDN / 字体依赖
- 边缘：JS 禁用时天然回退中文全量展示（现有机制已保证）

## 5. 验收标准

1. 本地起服务预览，桌面 / 平板 / 手机三种宽度确认无破版
2. 双语完整性：每段 zh/en 成对存在，切换无遗漏
3. 全部链接（2 个 PDF、锚点、mailto、GitHub 仓库、二维码图）逐一可点
4. Lighthouse 性能 / SEO ≥ 95
5. 推送后线上验证 `curl -I https://www.cyclone-xil.com/` 返回 200 且标题正确

## 6. 明确不做（YAGNI）

- 不扩多页站点、不建文档子站、不接表单后端、不引入前端框架、不做愿景口号式品牌叙事
