确定性 XiL 场景测试内核

The deterministic XiL scenario testing kernel

Cyclone 把 ADAS / 机器人回归测试收进一条流水线：数据回放 → 故障注入 → 统计判定 → 证据链。PASS 不再是"跑过一次没红"，而是可复现、可审计的机器证明。

Cyclone turns ADAS / robotics regression testing into one pipeline: replay → fault injection → statistical verdict → evidence chain. A PASS is no longer "it went green once" — it is reproducible, auditable machine proof.

仿真测试 = 用工程学造证据，用统计学下结论。

Simulation testing = engineering builds the evidence; statistics draws the verdict.

可靠性测试Reliability已支持Supported

seed 矩阵跑 300 把，成功率进 Wilson/SPRT——300/300 才能以 95% 置信声明 ≥ 99% 可靠性；soak 长测盯内存泄漏与计数器溢出。报告写"0.99（95% CI 下界，n=300，case hash 可复算）"。

A seed matrix of 300 runs feeding Wilson/SPRT — only 300/300 supports a ≥ 99% reliability claim at 95% confidence; soak runs watch memory leaks and counter overflows. The report reads "0.99 (95% CI lower bound, n=300, case hash recomputable)".

方法论：阈值是推导出来的Methodology: thresholds are derived, not guessed

验收线为什么定在 0.98 而不是 0.95？答不上来的阈值是装饰——定松了拦不住退化，定紧了冤杀健康版本。裕度分析三步法把答案写出来：

Why is the acceptance line at 0.98 and not 0.95? A threshold you can't explain is decoration — too loose it misses regressions, too tight it kills healthy builds. The three-step margin analysis derives the answer:

① 跑基线Run the baseline

不注故障跑若干轮，得到指标基线——一个分布，不是一个数（演示例：近距召回 0.9931）。

Run fault-free rounds to get the metric baseline — a distribution, not a number (demo example: near-range recall 0.9931).

② 定裕度Set the margin

阈值 = 基线 − 可接受退化量（演示例：收紧 1.3 个百分点，τ = 0.98）。

Threshold = baseline − acceptable degradation (demo example: tighten by 1.3 points, τ = 0.98).

③ 双向校验Verify both ways

故障场景必须 FAIL，基线必须 PASS——只验证一边，不算标定完成。

Fault scenarios must FAIL while the baseline must PASS — checking only one side is not calibration.

可行性判据：基线 CI 下界 > 故障 CI 上界，否则该故障强度下不可检 · 窗口相位：故障窗口 × 指标分箱 × 场景相位三者对齐 · 剂量-响应曲线：扫故障强度得鲁棒性剖面，是安全档案的高级素材

Feasibility criterion: baseline CI lower bound > fault CI upper bound, otherwise the fault is undetectable at that intensity · Window phasing: fault window × metric bin × scenario phase must align · Dose-response curve: sweep fault intensity for a robustness profile — first-class safety-case material
